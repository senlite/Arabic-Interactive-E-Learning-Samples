# Technology stack

Required technologies named in `Docs/Arabic-eLearning-Samples-Requirements.md`. Nothing else is part of this stack.

- HTML5
- CSS
- Vanilla JavaScript (ES2018+)
- Pointer Events
- Google Fonts: Cairo
- Google Fonts: Tajawal or IBM Plex Sans Arabic
- Font fallbacks: Noto Sans Arabic, Tahoma
- WebP
- SVG
- SCORM 1.2
- Node.js, used only by the packaging script
- npm package `archiver`
- GitHub Pages
