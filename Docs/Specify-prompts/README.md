# speckit-specify prompts

Source: `Docs/Arabic-eLearning-Samples-Requirements.md` (v1.0, 2026-11-04).

Run one prompt per `/speckit-specify` invocation, in this order. Paste the body of the file (everything under the heading) as the feature description.

| Order | File | Feature |
|---|---|---|
| 1 | `01-shared-runtime.md` | Repo shell, shared RTL/SCORM runtime, packaging script |
| 2 | `02-feedback-scenario.md` | Branching feedback scenario |
| 3 | `03-safety-challenge.md` | Gamified safety challenge |
| 4 | `04-scorm-package.md` | SCORM 1.2 zips and local LMS harness |
| 5 | `05-landing-readme.md` | Landing page, README, credits, Pages-ready paths |

Do not merge these into one specification. Learner-facing Arabic stays in the requirements file and must be copied verbatim when a later command implements the feature.
